# 1-st-game
This is a 2D game in which a knight is trying to collect coins and avoid being hit by slimes and monsters. All that to achieve his dream of being the richest Knight in his world.  
If another developer wants to continue making or developing the game, he/she must download GODOT 4.5.1 or another compatible version.  
This game features a movable animatable player, coins, a monster slime, and a moving platform.
